# Lumora
Smart web application for real-time mental health monitoring and early intervention among students.

# Overview
Lumora is a smart mental health monitoring web application designed to help students track their emotional well-being, identify early signs of stress or mental health risks, and receive personalized support.

The platform provides continuous mental health monitoring through mood tracking, self-assessment journals, behavioral insights, and data-driven recommendations. By leveraging modern web technologies and analytics, Lumora aims to encourage self-awareness and proactive mental health care among students.

This project was developed as part of a Final Year Project (FYP) at Universiti Teknikal Malaysia Melaka
